## Hi, I'm Sylesh Kona

Software engineer in New York building LLM agents, voice AI, and the evaluation systems that keep them honest. M.S. in Computer Science from the University at Albany (2026). Before that I was a software engineer at Rivian, building REST APIs and AWS monitoring for vehicle software services.

My projects share one idea: **let the model propose, let deterministic code decide, and check the result against real state instead of the transcript.**
